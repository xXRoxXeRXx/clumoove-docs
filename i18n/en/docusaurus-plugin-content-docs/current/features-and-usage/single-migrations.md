# One-Time Migrations

A migration transfers files, directories, calendars, or contacts between source and target profiles.

## Steps
1. Select **Source Profile** & browse folder tree.
2. Select **Target Profile** & target directory.
3. Configure resource types (`files`, `calendars`, `contacts`).
4. Set parallel threads (1-16).
5. Monitor real-time progress via Server-Sent Events (SSE).
