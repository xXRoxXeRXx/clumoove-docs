# Telekom MagentaCLOUD Setup

Telekom MagentaCLOUD uses standard WebDAV and can be connected using a generated WebDAV password.

## 1. Create WebDAV Password

1. Log into [MagentaCLOUD](https://magentacloud.de/).
2. Go to **Settings > Password & Security**.
3. Generate a password for external WebDAV apps.

## 2. Connect in Clumoove

1. Select **Add Connection > MagentaCLOUD**.
2. Endpoint: `https://magentacloud.de/remote.php/webdav/` (prefilled).
3. Username: Telekom email address.
4. Password: Generated WebDAV password.
