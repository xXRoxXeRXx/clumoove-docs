# SMB & SFTP Network Storage

Clumoove supports connecting SMB/CIFS Windows shares and SFTP SSH servers.

## SFTP
Requires Host, Port (22), Username, Password, and trusted **SSH Host Key SHA-256 Fingerprint**.

## SMB / CIFS
Requires Host IP/Name, Share Name, Username, and Password.
