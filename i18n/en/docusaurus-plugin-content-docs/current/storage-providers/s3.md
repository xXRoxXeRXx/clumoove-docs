# Amazon S3, MinIO & S3-Compatible Storage

Clumoove supports AWS S3, MinIO, Wasabi, Backblaze B2, Ceph, and Cloudflare R2.

## Connection Settings

| Form Field | Description | Example |
|---|---|---|
| **Server / Endpoint URL** | S3 API endpoint | `https://s3.eu-central-1.amazonaws.com` |
| **Access Key ID** | S3 Access Key | `AKIAIOSFODNN7EXAMPLE` |
| **Secret Access Key** | S3 Secret Key | `wJalrXUtnFEMI/K7MDENG...` |
| **Bucket Name** | Target/Source Bucket | `my-migration-bucket` |
| **Region** | S3 Region | `eu-central-1` |
