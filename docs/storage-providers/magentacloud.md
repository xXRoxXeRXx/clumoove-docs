# Telekom MagentaCLOUD Setup

Telekom MagentaCLOUD basiert auf dem WebDAV-Protokoll und kann ohne zusätzliche Entwickler-Registrierung direkt über deine Telekom-Anmeldedaten und ein WebDAV-Passwort verbunden werden.

## 1. WebDAV-Passwort im Telekom Kundencenter erstellen

1. Logge dich im [Telekom Kundencenter / MagentaCLOUD](https://magentacloud.de/) ein.
2. Gehe in die **Einstellungen > Passwort & Sicherheit**.
3. Erstelle ein spezielles **Passwort für externe Apps / WebDAV**.
4. Kopiere deinen Benutzernamen (E-Mail-Adresse) und das generierte WebDAV-Passwort.

## 2. Verbindung in Clumoove anlegen

1. Gehe in Clumoove auf **Verbindung hinzufügen > MagentaCLOUD**.
2. **Server-URL**: Wird von Clumoove automatisch vorgegeben (`https://magentacloud.de/remote.php/webdav/`).
3. **Benutzername**: Deine Telekom E-Mail-Adresse.
4. **Passwort**: Das im Telekom-Portal generierte **WebDAV-Passwort**.
5. Klicke auf **Verbindung testen & Speichern**.
