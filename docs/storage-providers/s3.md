# Amazon S3, MinIO & S3-Kompatible Objektspeicher

Clumoove unterstützt alle S3-kompatiblen Objektspeicher (Amazon AWS S3, MinIO, Wasabi, Backblaze B2, Ceph, Cloudflare R2).

## Verbindungseinstellungen in Clumoove

Wähle **Verbindung hinzufügen > S3 Storage**:

| Formularfeld | Beschreibung | Beispiel (MinIO / AWS) |
|---|---|---|
| **Server / Endpoint URL** | S3 API Endpunkt | `https://s3.eu-central-1.amazonaws.com` oder `http://minio.local:9000` |
| **Access Key ID** | S3 Zugriffsschlüssel | `AKIAIOSFODNN7EXAMPLE` |
| **Secret Access Key** | S3 Geheimschlüssel | `wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY` |
| **Bucket Name** | Ziel-/Quell-Bucket | `my-migration-bucket` |
| **Region** | S3 Region | `eu-central-1` (oder `us-east-1`) |

:::warning SSRF & Insecure Endpoints
Wenn du einen lokalen MinIO-Server ohne SSL (`http://...`) nutzt, prüft Clumoove aus Sicherheitsgründen, dass es sich um eine valide lokale IP (`127.0.0.1`, `192.168.x.x`) oder Domain (`*.local`, `localhost`) handelt, um SSRF-Angriffe zu verhindern.
:::
